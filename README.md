## 📖 About This Repository

This repository serves as a centralized knowledge base and operational handbook for modern bug bounty hunting. It brings together essential tools, structured methodologies, vulnerability checklists, and practical command references into one organized resource. 

Whether you are mapping out an attack surface, hunting for logic flaws, or verifying complex API vulnerabilities, you will find the necessary workflows here.

## 🎯 The Recon Command Handbook

A major component of this repository is the **Recon Command Handbook**. Reconnaissance is the foundation of a successful hunt. 

**Core Reconnaissance Coverage:**
* **Subdomain Enumeration:** Passive and active asset discovery.
* **DNS Reconnaissance:** DNS resolution, records, and validation.
* **Live Host Discovery:** HTTP probing and technology fingerprinting.
* **URL & Content Discovery:** Historical URLs, crawling, directory, and file discovery.
* **Parameter & JS Analysis:** Identifying testable parameters and extracting client-side assets.
